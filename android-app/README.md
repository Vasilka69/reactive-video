# Android Client

Android клиент на Kotlin для backend из корня репозитория.

Структура проекта:
- `ru.vasili4.reactivevideo.data` — preferences, модели, network и repository
- `ru.vasili4.reactivevideo.ui` — экраны, адаптеры и общие UI-утилиты

Реализовано:
- логин и регистрация
- хранение JWT и настраиваемого backend URL
- список бакетов, создание и удаление бакетов
- загрузка файлов в выбранный бакет
- список файлов пользователя
- просмотр изображений и видео
- просмотр текстовых файлов и запуск text-to-speech
- распознавание объектов на изображении с обычным и cached-сценарием
- скачивание и удаление файлов

Дефолтный backend URL:

`http://10.0.2.2:8081/`

Это адрес для Android Emulator. Для реального устройства URL можно поменять прямо в приложении.
